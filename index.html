Photo Culler

Browse and cull photos stored in Google Drive. Sign in once, then pick any folders.

One-time setup — get your OAuth Client ID
  1. Go to console.cloud.google.com → create a new project.
  2. Search Google Drive API → Enable it.
  3. Go to APIs & Services → OAuth consent screen.
    Choose External, fill in app name, add your email as a Test user.
  4. Go to Credentials → Create Credentials → OAuth 2.0 Client ID.
    Type: Web application.
  5. Under Authorized JavaScript origins, add:
    http://localhost:8080 and https://aspen404.github.io
  6. Save → copy the Client ID (ends in .apps.googleusercontent.com).
  7. Serve locally: python3 -m http.server 8080
  8. Open http://localhost:8080/photo-culler.html in Chrome.

⚠ Must be served from a registered origin — file:// URLs won't work for OAuth.

Access token stays in memory only · Never leaves your browser
